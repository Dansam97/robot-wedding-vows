A one-line robot wedding vow, written by a small Python program. The program writes a single line of wedding vows for a robot couple — a promise that holds in low battery and in full charge — to entry.txt in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
